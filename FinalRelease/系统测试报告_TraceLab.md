## 3. 自动化系统子测试

### 3.1 功能基本流与备选流

Playwright 在三种浏览器、两个桌面视口中重复执行：

1. 打开项目列表。
2. 提交空名称和全空格名称，验证提示“请输入项目名称”且不创建项目。
3. 创建带说明的本地项目，验证自动进入对应工作台。
4. 返回列表，定位刚创建的项目并重新打开同一项目 ID。
5. 检查工作台页面无横向溢出。
6. 检查非预期 HTTP 失败、控制台错误和页面异常。
7. 删除本轮测试数据。

结果为 **6 passed / 0 failed，31.0 秒**。该流程直接支持 TC-F-001、TC-F-002、TC-F-003；没有把它扩大解释为 PDF、代码、追溯或 Agent 全流程通过。

## 5. 易用性检查

自动化已验证空白输入有明确反馈、创建后自动进入工作台、列表可重新定位并打开项目，以及两个桌面视口无横向溢出。这些是易用性子证据，不满足 TC-U-001 至 TC-U-004 要求的三名非当前模块作者独立操作、键盘/辅助技术和主观观察，因此四条正式用例保持未执行。

## 6. 缺陷与修复

- BUG-20260728-001：空白项目名称按钮被禁用，已有校验提示不可触发。已移除提前禁用并由提交处理显示提示，6 组浏览器回归通过。
- BUG-20260728-002：Web 页面缺少 favicon，Chromium 控制台产生资源 404。已复用桌面 32x32 图标，生产构建确认图标被打包，浏览器回归通过。
- TEST-20260728-001：完整后端在 Python 3.14 覆盖率插桩下，论文后台任务的 5 秒轮询偶发超时。正式门禁拆分为“定向覆盖率 + 无插桩全量回归”；全量回归 223 条通过。

详情见 缺陷清单_TraceLab.md。
