# TraceLab 系统测试用例

## 文档说明

- `系统测试用例_TraceLab.xlsx` 是历史基线，仅用于追溯原始用例。
- 本文件是后续维护、评审和执行记录的主文件；新增或修改用例时优先更新本文件。
- 本文件从历史工作簿完整迁移 44 条用例，并根据 VS Code 扩展、修改冲突分析、桌面终端、RAG、手工标注、Agent 追溯 CRUD、六维置信度和同步增强累计新增 30 条用例；当前共 74 条：功能测试 59 条、易用性测试 7 条、兼容性测试 7 条、可选可靠性测试 1 条。
- 原工作簿的“实际结果”“是否通过”“缺陷严重等级”均为空。本文件不推测执行结果；2026-07-28 起仅依据实际日志、JUnit 和截图更新执行状态。
- 云端用例 `TC-F-029` 至 `TC-F-036` 统一标记为“待环境确认 / 可选范围”，须在云端功能和 staging 环境就绪后确认是否纳入当次发布验收。
- Safari、macOS、Windows 桌面环境等兼容性结论只能依据对应真实环境的执行证据填写，不得根据其他平台结果推测通过。

## 执行记录约定

- **状态**：未执行 / 通过 / 失败 / 阻塞 / 不适用。
- **实际结果**：记录关键观察、日志或截图路径；未执行时保持“待填写”。
- **缺陷**：记录缺陷编号及严重等级；未执行时保持“待填写”，不得填写“无缺陷”。
- **执行人 / 日期**：格式建议为“姓名 / YYYY-MM-DD”。
- **适用版本**：记录提交号、构建号或发布版本。
- **范围标记**：必测 / 待环境确认（可选范围）/ 可选。
